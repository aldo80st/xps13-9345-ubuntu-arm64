### Revisión de seguridad de scripts de referencia

Se inspeccionaron **sin ejecutarlos** los scripts `01-fix-cdsp-firmware.sh`, `02-stage-dsp-files.sh`, `03-boot-reliability.sh`, `04-verify-npu.sh`, `05-run-llm-on-npu.sh` de `UnsignedChad/t14s-x1e-npu`:

- `01` sustituye firmware en ruta **Lenovo**, asume partición y rutas fijas. **No aplica a Dell y se prohíbe su ejecución.** La rama HAMOA-1 ya se observó en el firmware Dell.
- `02` ejecuta como root, monta un volumen, copia binarios DSP y arranca `cdsprpcd`. No debe reutilizarse sin adaptar rutas/procedencia, licencia y rollback.
- `03` instala un servicio de apagado y escribe estados `remoteproc`. Su efecto sobre estabilidad y orden de apagado requiere diseño/revisión específica.
- `04` inicia un servicio y realiza pruebas reales; captura salidas con `grep ... || true`. El exit code puede quedar oculto; **no usarlo como veredicto automático de PASS**.
- `05` arranca servicio y ejecuta Genie; para generar contexto LLM cita compilación en host x86 y SDK compatible. No asumir que ya existen modelos listos.

### Licencias

`geniex-qairt-plugin` se publica bajo **BSD-3-Clause**, pero su `THIRD_PARTY_NOTICES.md` indica que `qnn-api/` y las bibliotecas QAIRT vendorizadas siguen bajo la **EULA Qualcomm**. Por tanto, **no** tratar estos blobs como software libre ni incluirlos en nuestro repositorio sin revisar derechos de distribución. SHA256 y procedencia siguen pendientes hasta seleccionar una versión concreta.

### Puertas para M2 (todavía NO superadas)

1. **Q-001:** seleccionar build QNN/Genie ARM64 y validar requisitos de ABI, licencia, soporte HTP v73 y procedencia; registrar hashes antes de instalar.
2. **Q-002:** ubicar shells DSP **compatibles con firmware Dell HAMOA-1** y daemon `cdsprpcd` legítimamente obtenidos, sin copiar paquetes Lenovo a ciegas.
3. Diseñar permisos de mínimo privilegio sin dejar `/dev/fastrpc*` abierto a todos; revisar implicaciones de acceso root y contenedores `--privileged`.
4. Preparar pruebas con timeout, detección de exit code real y recuperación de DSP validada; no `SIGKILL` sobre RPC activo sin procedimiento de seguridad.
5. Obtener autorización específica **antes** de instalar paquetes, compilar código, lanzar validador/modelos, alterar permisos, servicios o reiniciar.
