# XPS AUTHZ v1.1 — IPC framing laboratory candidate

This code is a pure transport component. It does not listen on a host socket, grant permissions, call sudo, load modules, invoke units, install software or alter hardware. A separately reviewed root-owned service would supply an exact dedicated UID/GID, a filesystem-owned socket and a trusted policy adapter. The agent retains NoNewPrivileges and zero capabilities.

AF_UNIX SOCK_STREAM, Linux SO_PEERCRED, one ASCII catalog command terminated by LF and EOF after write-half shutdown. Allowed: status, audit, iris-r0, thermal. At most 8 bytes, absolute 2-second receive deadline, reject trailing data. Grant/revoke/recovery and arbitrary argv/path are not exposed. Response is bounded JSON with enumerated result/reason, operation ID, bounded operation phase/outcome and counters. The handler never retries a request after transport failure; query status and durable receipts instead. Status uses a separate read-only provider, never the action dispatcher. Admission and effect durability belong to the policy engine. A trusted dispatch adapter is required and must have its own bounded service lifetime; handler has no generic command runner.

Tests use socketpair and same non-root UID/GID; negative credential mismatch, root identity rejection, invalid commands, trailing data, incomplete frame, bad responses and disconnect are exercised. This does not prove distinct-UID native isolation, filesystem permissions, active socket activation or remote connector migration. All remain gates M3/M4/M5. No root operations or installation here.
